# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub's security advisory form](https://github.com/acroca/review-sieve/security/advisories/new).
Do not disclose credentials or vulnerability details in a public issue.
Include the affected version, a description, and reproduction steps where possible.

Use a narrowly scoped GitHub token and keep it out of source control, logs,
and container images. Revoke and replace any token that may have been exposed.
